# Portfolio Chat

A modern Next.js portfolio with an AI-powered chat assistant.

## Overview

This project is a personal portfolio built with Next.js and React, featuring:

- animated landing page with custom particles and visual effects
- AI chat assistant powered by Google Generative AI in `app/actions.ts`
- custom UI components in `components/ui/`
- responsive layout and Tailwind CSS styling
- dynamic homepage content and portfolio sections

## Tech stack

- Next.js 16.2.4
- React 19.2.4
- Tailwind CSS v4
- TypeScript
- Framer Motion, Lucide React, Radix UI

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the app at:

```bash
http://localhost:3000
```
